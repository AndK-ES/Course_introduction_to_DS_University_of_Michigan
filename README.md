# Introduction to Data Science — University of Michigan

Personal study notes and code exercises for the Coursera course **"Introduction to Data Science"** offered by the **University of Michigan**.

## Overview

This repository contains 4 modules of interactive Jupyter notebooks covering fundamental data science concepts, progressing from Python basics through statistical inference. Each module includes lecture notes, code examples, and real-world dataset analysis.

## Modules

| Module       | Topics                                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------------------ |
| **Module 1** | Python fundamentals, CSV processing, OOP, NumPy arrays, boolean indexing, image manipulation with PIL              |
| **Module 2** | Pandas Series & DataFrames, label-based/position-based indexing, CSV loading, vectorized operations                |
| **Module 3** | Advanced Pandas: merging/joining DataFrames, method chaining, `apply()`, grouping, census data analysis            |
| **Module 4** | Statistical testing: independent t-tests with `scipy.stats`, multiple testing & Type I errors, grade data analysis |

## Technologies

- **Python 3** — core language
- **Jupyter Notebooks** — interactive learning environment
- **NumPy** — array operations and numerical computing
- **Pandas** — data manipulation and analysis
- **SciPy** — statistical hypothesis testing
- **Pillow (PIL)** — image processing

## Datasets

Notable datasets used across modules:

- `mpg.csv` — fuel economy data for 234 vehicles
- `winequality-red.csv` — red wine physicochemical properties
- `Admission_Predict.csv` — graduate admission records
- `census.csv` — US Census population estimates (3193 counties)
- `grades.csv` — student assignment grades with timestamps
- `customers-100.csv` — synthetic customer data
